# AGENTS.md — Proyecto [Nombre del sistema del alumno]

## 1. Lee la especificación
Antes de empezar a programar, lee el documento del proyecto que está en esta carpeta (el archivo `.docx` o `.md` que subió el alumno). De ahí salen los requisitos funcionales, las pruebas de aceptación y las prioridades.

## 2. Stack de desarrollo (definido con el profesor)
- **Frontend:** React con Vite,audio html5 express
- **Backend:** postgresql, express

## 3. Reglas de trabajo
- Implementa una funcionalidad a la vez (una RF o PA por iteración).
- Después de cada cambio, ejecuta el comando de pruebas: `npm test`.
- Si una prueba falla, corrige el código, no la prueba.
- No modifiques el archivo `.env`.

## 4. Terminado significa
Todas las pruebas de aceptación (PA-01, PA-02, …) pasan en verde y los requisitos "Must" están cubiertos.
